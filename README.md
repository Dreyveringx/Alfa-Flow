# ARKTEX Alpha-Flow Pro - Portafolio Digital de Marketing

## Descripción

Portafolio digital de marketing premium de 8 diapositivas para la chaqueta **Arkitex Alpha-Flow Pro**. Diseñado con un estilo visual innovador que refleja "Tecnología Nocturna, Alto Rendimiento" con efectos de neón y diseño futurista.

## Características del Diseño

- **Estilo Visual**: Tecnología Nocturna, Alto Rendimiento
- **Paleta de Colores**:
  - Primario: Negro Absoluto (fondo dominante)
  - Secundario: Gris Oscuro (textos de contraste)
  - Acentos Neón: Azul Eléctrico, Naranja Neón, Verde Lima Neón
- **Tipografía**: Montserrat (moderna, sans-serif, alta tecnología)
- **Efectos**: Líneas de neón, circuitos sutiles, efectos de bokeh, animaciones suaves

## Estructura de las 8 Diapositivas

1. **Portada** - Máximo Impacto: Título "Alpha-Flow Pro" con efecto neón y imagen de la chaqueta
2. **Quiénes Somos** - La Visión: Presentación de ARKTEX y su misión
3. **Qué Vendemos** - El Producto: Características principales de la chaqueta
4. **Qué Prometemos** - La Propuesta de Valor: Tres promesas clave con iconos minimalistas
5. **Cómo se Cumple** - Tecnologías: Tres pilares tecnológicos (Alpha-Flow, Illumination, Smart Pockets)
6. **Beneficios y Resultados** - Para el Cliente Activo: Resultados tangibles para usuarios
7. **Nuestro Público** - Casos de Éxito: Perfil del público objetivo
8. **Precio y Contacto** - CTA Final: Precio, opciones de color e información de contacto

## Cómo Usar

### Opción 1: Abrir directamente
1. Abre el archivo `index.html` en tu navegador web moderno (Chrome, Firefox, Edge, Safari)

### Opción 2: Servidor local (recomendado)
```bash
# Con Python 3
python -m http.server 8000

# Con Node.js (http-server)
npx http-server

# Con PHP
php -S localhost:8000
```

Luego abre `http://localhost:8000` en tu navegador.

## Navegación

- **Flechas de navegación**: Botones en la barra lateral derecha
- **Puntos de navegación**: Clic en los puntos para saltar a cualquier diapositiva
- **Teclado**: 
  - Flecha derecha/abajo: Siguiente diapositiva
  - Flecha izquierda/arriba: Diapositiva anterior
- **Touch/Swipe**: Desliza izquierda o derecha en dispositivos táctiles

## Archivos Incluidos

- `index.html` - Estructura HTML de la presentación
- `styles.css` - Estilos visuales y efectos de neón
- `script.js` - Funcionalidad de navegación e interacciones
- Imágenes de producto (formato AVIF y PNG)
- Video promocional (Multimedia1.mp4)

## Características Técnicas

- Diseño responsive (adaptable a móviles y tablets)
- Animaciones CSS suaves
- Efectos de neón con sombras y brillos
- Patrones de fondo con circuitos
- Mockup de smartphone con interfaz de app
- Transiciones suaves entre diapositivas
- Optimizado para rendimiento

## Personalización

Para modificar colores, edita las variables CSS en `styles.css`:

```css
:root {
    --neon-blue: #00ffff;
    --neon-orange: #ff6600;
    --neon-lime: #ccff00;
}
```

## Compatibilidad

- Navegadores modernos (Chrome, Firefox, Safari, Edge)
- Dispositivos móviles y tablets
- Resoluciones desde 320px hasta 4K

## Notas

- Las imágenes deben estar en la misma carpeta que `index.html`
- El video puede integrarse usando la etiqueta `<video>` si se desea
- El diseño está optimizado para presentaciones en pantalla completa (F11)
